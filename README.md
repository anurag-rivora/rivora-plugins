# Rivora plugins

Plugins that connect coding agents to [Rivora Product OS](https://rivoraconnect.com.au).

Rivora turns a feature request into a reviewed feature pack. When the pack is approved, Rivora
freezes it into a version-pinned handoff. These plugins let your coding agent find that handoff,
read it, check its open questions and build from it. You sign in with your Rivora account; no
token is copied.

| Tool | Folder | Install |
|---|---|---|
| Claude Code | [`claude-rivora`](claude-rivora) | `claude plugin marketplace add anurag-rivora/rivora-plugins`, then `claude plugin install rivora@rivora` |
| Cursor | [`cursor-rivora`](cursor-rivora) | From the Cursor Marketplace, or see the folder's README |

Claude (claude.ai), ChatGPT and Codex connect straight to the Rivora server:
`https://api.rivoraconnect.com.au/mcp/`

## What a connected agent can do

- **Read** approved handoffs in the workspace you choose. Drafts never leave Rivora.
- **Suggest** changes, only if you allow it when you sign in. A person reviews each suggestion
  on the feature pack.
- **Never** change an approved output, an approval or the feature pack.
